Using Zer

Obfuscator

Paste or upload a Luau script, choose your protection options, and press Obfuscate. The output can be copied, downloaded, or shared to Rubiš/Pastebin directly from the same tab. No access key needed — this tab is open to anyone.

Key & Lua Script

Protected with an access key (the same value as your server's ADMIN_KEY). Unlock it once and the browser remembers you — you won't be asked again unless you press Lock. The Key tab issues Free or Premium license keys with a chosen duration; the Lua Script tab manages your saved scripts and generates loaders that can bundle multiple scripts together.

What does obfuscation do?

Zer rewrites your Luau source so it still runs exactly the same, but is much harder for anyone else to read or reverse-engineer. Variable names get scrambled, strings get encrypted, and — if you turn on virtualization — your logic compiles down to bytecode that runs on a custom VM embedded in the output.

Will it change how my script runs?

No. Obfuscation only changes the shape of the code, not its behavior. Roblox globals stay untouched by default so your game APIs keep working.

Is this unbreakable?

No obfuscator is. Virtualization at the Max hardening grade makes static analysis and deobfuscation significantly harder, but a determined reverse-engineer can still work through it given enough time.
