Security architecture

Multiple layers, one pipeline

Sensitive Lua and Luau logic passes through several layers of code transformation and runtime protection before it ever reaches a player's client.

Dynamic anti-dumper defense

Runtime protection designed to make automated inspection and unauthorized memory analysis more difficult to carry out cleanly.

Custom VM virtualization

Selected logic is compiled into a custom execution layer with instruction structures that are randomized on every build.

Anti-tamper & runtime integrity

Execution conditions are monitored continuously to flag unexpected runtime modifications while a script is running.

Analysis resistance

Additional structural layers raise the effort required for automated tooling to statically analyze a protected script.

Roblox & Luau optimized

Built around the shape of real Lua and Luau projects, keeping compatibility with common scripting patterns intact.

Client-side privacy

Code is processed directly in your browser whenever possible, keeping unnecessary server-side exposure to a minimum.
